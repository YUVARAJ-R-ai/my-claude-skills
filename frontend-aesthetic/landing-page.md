# Landing Page Mode

Use this mode for marketing websites and public-facing product pages.

## Recommended Narrative

A strong default structure is:

NAV
→ HERO
→ REAL PRODUCT DEMO
→ SOCIAL PROOF
→ CORE PRODUCT STORY
→ WORKFLOW/FEATURE
→ AUTHENTIC PRODUCT UI
→ TECHNICAL/INFRASTRUCTURE STORY
→ METRICS
→ CUSTOMERS/TESTIMONIALS
→ INTEGRATIONS
→ FINAL CTA
→ FOOTER

Do not blindly use this order. Product narrative wins.

## Hero

Use:
- small eyebrow
- strong headline
- short supporting copy
- one primary CTA
- optional secondary CTA
- immediate product-specific visual

Prefer real product UI immediately after or within the hero.

Avoid:
- vague slogans
- huge decorative 3D objects with no product connection
- multiple competing CTAs
- gradient text by default

## Product Storytelling

Replace generic feature-card grids with:
- real workflows
- product screens
- diagrams
- annotated interfaces
- data visualizations
- architecture illustrations where useful

The product UI should explain the product.

## Section Rhythm

Do not repeat:
text → three cards → text → three cards.

Vary composition:
- text + product UI
- full-width product scene
- metric + explanation
- workflow
- split layout
- dense technical section
- testimonial/editorial section

Change composition while keeping tokens consistent.

## Social Proof

Use real logos, real claims, and real customer context when available.
Never invent customer names, statistics, testimonials, or awards.

## CTA

Keep the final CTA simple and intentional. Avoid giant gradient blocks unless they are genuinely part of the brand.
